PREGUNTA 1 (5 pts)
¿Cuál es la diferencia entre "git add" y "git commit"?

Tu respuesta:
Con git add agrego o sugiero los cambios que se harán y el git commit es para agregarlo para siempre al historial.

----------------------------------------------------------------
PREGUNTA 2 (5 pts)
¿Qué hace el comando "git pull"? ¿Cuándo debes usarlo?

Tu respuesta:
El git pull sirve para actualizar tu repositorio local con los cambios más recientes del repositorio remoto

----------------------------------------------------------------
PREGUNTA 3 (5 pts)
¿Qué diferencia hay entre un repositorio local y uno remoto?

Tu respuesta:
El local esta en tu propia computadora y puedes trabajar sin conexion mientras que el remoto esta en un servidor compartido

----------------------------------------------------------------
PREGUNTA 4 (5 pts)
Escribe la secuencia completa de comandos para subir un nuevo
archivo llamado "datos.csv" a GitHub (desde git add hasta push):

Tu respuesta:
git add datos.csv
git commit -m "Agregar datos.csv"
git push origin main
